# Rolecraft
Free browser-side resume/JD matching. No API key required.
Instant mode ranks existing skills and whole projects, preserves their technologies, and lists missing tools as suggestions.
Optional WebLLM browser AI downloads a model and requires WebGPU and sufficient device memory. Wording must be reviewed.
Run `npm start`, then visit http://localhost:4173. Run `npm test` for validation.
Resume content stays in the browser. External libraries and optional model assets are downloaded. No Groq calls.
